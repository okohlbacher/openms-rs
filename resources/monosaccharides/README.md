# Pinned ProForma monosaccharide records

`monosaccharides.json` is copied byte-for-byte from
[OpenMS4-core revision 82ce5b3](https://github.com/okohlbacher/OpenMS4-core/blob/82ce5b373c97f934ffd9b1ffd80215ca66473d0b/share/OpenMS/CHEMISTRY/monosaccharides.json).
Its original `_metadata` identifies `HUPO-PSI/ProForma monosaccharides/mono.obo`,
records a source synchronization date of 2026-01-13, and retains the original
source URL. These source-provided provenance fields are preserved, not treated
as an independent verification of the current remote ontology.

The 24 records contain 36 distinct primary/alias lookup keys. `monosaccharides.rs`
is a literal projection generated by
[tools/generate_monosaccharides.py](../../tools/generate_monosaccharides.py),
with unchanged names, formulas, synonym order and stored binary64 masses.
The [manifest](../../tests/data/monosaccharide_provenance.json) records exact
source/resource/generator hashes. See
[the support contract](../../docs/MONOSACCHARIDE_SUPPORT.md) for source precedence
and the explicit built-in-only runtime boundary.

Regenerate with `python3 tools/generate_monosaccharides.py`; verify with the same
command plus `--check`. Neither command needs a compiler, network or nonstandard
Python package.
