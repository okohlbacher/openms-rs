# Pinned RNA data

This unpublished local port retains the RNA inputs from the user-selected
[OpenMS4-core revision 7c029e8](https://github.com/okohlbacher/OpenMS4-core/tree/7c029e8cdba6abab503708ecdd56f6ab55e38ce4/share/OpenMS/CHEMISTRY).
[Provenance](provenance.json) records their exact hashes and the transformation.

The default registry uses [Modomics.json](Modomics.json), then
[Custom_RNA_modifications.tsv](Custom_RNA_modifications.tsv). The JSON has 424
objects, of which 333 have accepted nonempty codes. The custom table adds 45
records. Iteration retains all 378 records; exact lookup retains the last of
each of 375 distinct codes. The legacy [Modomics.tsv](Modomics.tsv), with 172
records, is retained to exercise the separate TSV reader and its original notice.
It is not a third default provider.

[ribonucleotides.rs](ribonucleotides.rs) is the embedded projection, generated by
[the standard-library Python generator](../../tools/generate_ribonucleotides.py).
This allows the default registry to work without JSON parsing or runtime files.
Record strings and explicit mass literals are retained; masses absent from JSON,
or explicitly zero in applicable TSV fields, use the corresponding source
formula fallback. Those fallback masses follow the port's audited elemental
tables and deterministic element ordering. C++ pointer-map summation order is
not asserted as a portable binary contract.

Regenerate or verify without a compiler:

```sh
python3 tools/generate_ribonucleotides.py
python3 tools/generate_ribonucleotides.py --check
```

The JSON adapter is enabled by the optional `rna-json` feature, included among
default features. It uses serde_json with correctly rounded float parsing and
sorted object keys. The TSV and in-memory interfaces require no parser dependency.
Tests compare every embedded record with independent source-field fixtures and
with the native providers.

## Data notices and release boundary

The BSD-3-Clause software license does not relicense the MODOMICS dataset.
The upstream legacy TSV explicitly says “Data used with permission” and cites
the [2017 MODOMICS update](https://doi.org/10.1093/nar/gkx1030). The pinned JSON
contains no separate license notice. OpenMS custom definitions retain their
OpenMS provenance and are separate from the MODOMICS data.

The authors describe data as freely accessible for research in the
[2021 update](https://academic.oup.com/nar/article/50/D1/D231/6454677).
The current [MODOMICS download page](https://genesilico.pl/modomics/download)
asks users to cite its publications. These statements were inspected on
2026-09-10; they do not establish a general redistribution license for the
pinned JSON or its transformed records. The article's own publication license
is not treated as a dataset license.

The complete snapshot is used here for local source analysis and scientific
validation. Dataset redistribution terms remain unresolved for release; no
package has been published and no permissive data license is claimed. Keeping
the complete source projection does not remove that release requirement.
The generic readers and caller-owned record APIs are implemented independently
of any particular dataset's redistribution terms.

For research using MODOMICS, retain its requested scientific attribution. The
current download page identifies Sordyl et al., *MODOMICS: a database of RNA
modifications and related information. 2025 update and 20th anniversary*,
[doi:10.1093/nar/gkaf1284](https://doi.org/10.1093/nar/gkaf1284). The original
snapshot's historical TSV attribution is preserved byte for byte.
