Usage:
  B7MapAlignerNone <options>

Options (mandatory options marked with '*'):
  -in <files>*                Input files to align (all must have the same file type) (valid formats: 'featureXML', 'consensusXML')
  -out <files>                Output files (same file type as 'in'). This option or 'trafo_out' has to be provided; they can be used together. (valid formats: 'featureXML', 'consensusXML')
  -trafo_out <files>          Transformation output files. This option or 'out' has to be provided; they can be used together. (valid formats: 'trafoXML')
  -in_spectra_files <files>   Optional input spectra files (mzML) that will be transformed along with the alignment. Size must match the number of input files. (valid formats: 'mzML')
  -out_spectra_files <files>  Optional output spectra files (mzML) corresponding to transformed in_spectra_files. Size must match in_spectra_files. (valid formats: 'mzML')
  -store_original_rt          Keep the original retention times
