Usage:
  B7MapAlignerRestricted <options>

Options (mandatory options marked with '*'):
  -in <files>*                  Input files to align (all must have the same file type) (valid formats: 'featureXML', 'consensusXML')
  -out <files>                  Output files (same file type as 'in'). This option or 'trafo_out' has to be provided; they can be used together. (valid formats: 'featureXML', 'consensusXML')
  -trafo_out <files>            Transformation output files. This option or 'out' has to be provided; they can be used together. (valid formats: 'trafoXML')
  -in_spectra_files <files>     Optional input spectra files (mzML) that will be transformed along with the alignment. Size must match the number of input files. (valid formats: 'mzML')
  -out_spectra_files <files>    Optional output spectra files (mzML) corresponding to transformed in_spectra_files. Size must match in_spectra_files. (valid formats: 'mzML')

Options to define a reference file (use either 'file' or 'index', not both):
  -reference:file <file>        File to use as reference (same file format as input files required) (valid formats: 'featureXML', 'consensusXML')
  -reference:index <number>     Use one of the input files as reference ('1' for the first file, etc.).
                                If '0', no explicit reference is set - the algorithm will select a reference. (default: '0') (min: '0')

  -store_original_rt            Keep the original retention times
                                
Common UTIL options:
  -ini <file>                   Use the given TOPP INI file
  -log <file>                   Name of log file (created only when specified)
  -instance <n>                 Instance number for the TOPP INI file (default: '1')
  -debug <n>                    Sets the debug level (default: '0')
  -threads <n>                  Sets the number of threads allowed to be used by the TOPP tool (0 = all available cores) (default: '1')
  -write_ini <file>             Writes the default configuration file
  -write_ctd <out_dir>          Writes the common tool description file(s) (Toolname(s).ctd) to <out_dir>
  -write_nested_cwl <out_dir>   Writes the Common Workflow Language file(s) (Toolname(s).cwl) to <out_dir>
  -write_cwl <out_dir>          Writes the Common Workflow Language file(s) (Toolname(s).cwl) to <out_dir>, but enforce a flat parameter hierarchy
  -write_nested_json <out_dir>  Writes the default configuration file
  -write_json <out_dir>         Writes the default configuration file, but compatible to the flat hierarchy
  -no_progress                  Disables progress logging to command line
  -force                        Overrides tool-specific checks
  -test                         Enables the test mode (needed for internal use only)
