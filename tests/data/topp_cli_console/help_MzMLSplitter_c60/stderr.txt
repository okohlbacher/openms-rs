Usage:
  MzMLSplitter <options>

Options (mandatory options marked with '*'):
  -in <file>*        Input file (valid formats: 'mzML')
  -out <prefix>      Prefix for output files ('_part1of2.mz
                     ML' etc. will be appended; default: 
                     same as 'in' without the file extensio
                     n)
  -parts <num>       Number of parts to split into (takes 
                     precedence over 'size' if set) (defaul
                     t: '1') (min: '1')
  -size <num>        Approximate upper limit for resulting 
                     file sizes (in 'unit') (default: '0') 
                     (min: '0')
  -unit <choice>     Unit for 'size' (base 1024) (default: 
                     'MB') (valid: 'KB', 'MB', 'GB')
  -no_chrom          Remove chromatograms, keep only spectr
                     a.
  -no_spec           Remove spectra, keep only chromatogram
                     s.
                     
Common TOPP options:
  -ini <file>        Use the given TOPP INI file
  -threads <n>       Sets the number of threads allowed to 
                     be used by the TOPP tool (0 = all avai
                     lable cores) (default: '1')
  -write_ini <file>  Writes the default configuration file
  --help             Shows options
  --helphelp         Shows all options (including advanced)
