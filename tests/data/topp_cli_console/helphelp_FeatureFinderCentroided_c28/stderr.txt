Settings that determine 
which peaks are considered 
a seed:
  -algorithm:seed:min_score
                                                                      <value>                                  Minimum seed score a 
                                                                     peak has to reach to be used as seed.
                                                                     The seed score is the geometric mean of intensity score, mass trace score and isotope pattern score.
                                                                     If your features show a large deviation from the averagene isotope distribution or from an gaussian elution profile, lower this score. (default: 
                                                                     '0.8') (min:
                                                                      '0.0' max: '1.0')

Settings for the features 
(intensity, quality assessm
ent, ...):
  -algorithm:feature:min_sc
                                                                     ore <value>                               Feature score threshold 
                                                                     for a feature to be reported.
                                                                     The feature score is the geometric mean of the average relative deviation and the correlation between the model and the observed peaks. (default: 
                                                                     '0.7') (min:
                                                                      '0.0' max: '1.0')
  -algorithm:feature:min_is
                                                                     otope_fit <value>                         Minimum isotope fit of 
                                                                     the feature before model fitting. (defa
                                                                     ult: '0.8') 
                                                                     (min: '0.0' max: '1.0')
  -algorithm:feature:min_tr
                                                                     ace_score <value>                         Trace score threshold.
                                                                     Traces below this threshold are removed after the model fitting.
                                                                     This parameter is important for features that overlap in m/z dimension. (default: '0.5') (min
                                                                     : '0.0' max: '1.0')
  -algorithm:feature:min_rt
                                                                     _span <value>                             Minimum RT span in relat
                                                                     ion to extended area that has to remain after model fitting. (defa
                                                                     ult: '0.333') (min: '0.0' max: '1.0')
  -algorithm:feature:max_rt
                                                                     _span <value>                             Maximum RT span in relat
                                                                     ion to extended area that the model is allowed to have. (default: 
                                                                     '2.5') (min:
                                                                      '0.5')
  -algorithm:feature:rt_sha
                                                                     pe <choice>                               Choose model used for 
                                                                     RT profile fitting. If set to symmetric a gauss shape is used, in case of asymmetric an EGH shape is used. (default: 
                                                                     'symmetric') (valid: 'symmetric', 'asym

  -algorithm:feature:max_in
                                                                     tersection <value>                        Maximum allowed intersec
                                                                     tion of features. (default: '0.35')

  -algorithm:feature:report
                                                                     ed_mz <choice>                            The mass type that is 
                                                                     reported for features.
                                                                     'maximum' returns the m/z value of the highest mass trace.
                                                                     'average' returns the intensity-weighted average m/z value of all contained peaks.
                                                                     'monoisotopic' returns the monoisotopic m/z value derived from the fitted isotope model. (def
                                                                     ault: 'monoisotopic') (valid: 'maximum'
                                                                     , 'average', 'monoisotopic')
