Usage:
  BaselineFilter 
<options>

Options (mandatory 
options marked with
 '*'):
  -in <file>*      
                                       Input raw data 
                             file  
                             (valid formats: 'mzML')
  -out <file>*     
                                       Output raw data 
                             file  
                             (valid formats: 'mzML')
  -struc_elem_lengt
                             h <size>  Length of the stru
                             cturing element (should be wider than maximal peak width - see documentation). (defau
                             lt: '3.0')
  -struc_elem_unit 
                             <unit>    Unit of 'struc_ele
                             m_length' parameter. (defaul
                             t: 'Thomson') (valid: 'Thoms
                             on', 'DataPoints')
  -method <string> 
                                       The name of the 
                             morphological filter to be applied. If you are unsure, use the default. (default: 
                             'tophat') (valid: 'identity'
                             , 'erosion', 'dilation', 'opening', 'closing', 'gradient', 'tophat', 'bothat', 'erosion_simple', 'dilation_simple')
