
BaselineFilter -- Removes the baseline from profile spectra
 using a top-hat filter.
Full documentation: http://www.openms.de/doxygen/release/4.
0.0/html/TOPP_BaselineFilter.html

Usage:
  BaselineFilter <options>

Options (mandatory options marked with '*'):
  -in <file>*                   Input raw data file  (valid
                                 formats: 'mzML')
  -out <file>*                  Output raw data file  (vali
                                d formats: 'mzML')
  -struc_elem_length <size>     Length of the structuring 
                                element (should be wider 
                                than maximal peak width - 
                                see documentation). (defaul
                                t: '3.0')
  -struc_elem_unit <unit>       Unit of 'struc_elem_length'
                                 parameter. (default: 'Thom
                                son') (valid: 'Thomson', 
                                'DataPoints')
  -method <string>              The name of the morphologic
                                al filter to be applied. 
                                If you are unsure, use the 
                                default. (default: 'tophat'
                                ) (valid: 'identity', 'eros
                                ion', 'dilation', 'opening'
                                , 'closing', 'gradient', 
                                'tophat', 'bothat', 'erosio
                                n_simple', 'dilation_simple
                                ')

                                allowed to be used by the 
                                TOPP tool (0 = all availabl
                                e cores) (default: '1')

                                s).cwl) to <out_dir>, but 
                                enforce a flat parameter 
                                hierarchy
  -write_nested_json <out_dir>  Writes the default configur
                                ation file
  -write_json <out_dir>         Writes the default configur
