Usage:
  MzMLSplitter <options>

Options (mandatory options marked with 
'*'):
  -in <file>*        Input file (valid 
                     formats: 'mzML')
  -out <prefix>      Prefix for output 
                     files ('_part1of2.
                     mzML' etc. will 
                     be appended; defau
                     lt: same as 'in' 
                     without the file 
                     extension)
  -parts <num>       Number of parts 
                     to split into (tak
                     es precedence over
                      'size' if set) 
                     (default: '1') 
                     (min: '1')
  -size <num>        Approximate upper 
                     limit for resultin
                     g file sizes (in 
                     'unit') (default: 
                     '0') (min: '0')
  -unit <choice>     Unit for 'size' 
                     (base 1024) (defau
                     lt: 'MB') (valid: 
                     'KB', 'MB', 'GB')
  -no_chrom          Remove chromatogra
                     ms, keep only spec
                     tra.
  -no_spec           Remove spectra, 
                     keep only chromato
                     grams.
