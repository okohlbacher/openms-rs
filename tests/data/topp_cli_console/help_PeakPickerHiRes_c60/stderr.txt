Usage:
  PeakPickerHiRes <options>

This tool has algorithm parameters that are not shown here!
 Please check the ini file for a detailed description or 
use the --helphelp option

Options (mandatory options marked with '*'):
  -in <file>*        Input profile data file  (valid format
                     s: 'mzML')
  -out <file>*       Output peak file  (valid formats: 'mzM
                     L')
                     
Common TOPP options:
  -ini <file>        Use the given TOPP INI file
  -threads <n>       Sets the number of threads allowed to 
                     be used by the TOPP tool (0 = all avai
                     lable cores) (default: '1')
  -write_ini <file>  Writes the default configuration file
  --help             Shows options
  --helphelp         Shows all options (including advanced)


The following configuration subsections are valid:
 - algorithm   Algorithm parameters section

You can write an example INI file using the '-write_ini' 
option.
Documentation of subsection parameters can be found in the 
doxygen documentation or the INIFileEditor.
