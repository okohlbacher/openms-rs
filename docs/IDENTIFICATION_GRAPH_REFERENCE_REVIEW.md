## Semantic checks

The independent checks distinguish record identity from its mutable payload:

- Parent registration keys only on accession. Later nonempty sequence/description fills blanks or conflicts; decoy status is ORed, while original molecule type and coverage survive successful registration.
- Peptide and oligo keys use complete chemical sequence identity. Parent matches key on inclusive positions only: the first neighbors and metadata survive a duplicate-position merge.
- Applied processing steps retain their first insertion position. Updating an earlier step does not make it the latest step; lookup searches reverse insertion order. Software score priorities may contain duplicates, and the source score-order helper emits those duplicates.
- Ordinary processing-step registration preserves its first search-parameter association. Graph merge replaces that association with the translated incoming association, retains the destination active step and attaches it through ordinary scored-node registration. Copy separately preserves graph metadata and translates the incoming current step without adding another step to copied nodes.
- Unknown, reversed and out-of-range parent intervals can be stored, but coverage ignores invalid intervals. Optional molecule-length checks compare interval length with residue count. The source empty-parent `break` is retained under deterministic native ID order.

Native IDs include graph ownership and generation. Foreign and stale references fail instead of behaving like dangling source iterators. Native full chemical value identity replaces source allocation-address ties. Checked finite-value and resource failures are atomic; partial container changes after a C++ exception are not reproduced.

## Scope and limits

This increment covers input files, score types, processing software, database-search parameters, processing steps, scored history, parent sequences, identified peptides/oligos, reference translation, coverage and RNA digestion integration. It does not establish completion of observations, compounds, adduct registrations, observation matches, grouping, full cleanup, or `IdentificationDataConverter`. Existing legacy peptide/protein identification records remain separate APIs.

The packaged tests use literal source strings and native public operations; they do not need an installed C++ SDK or a `.reference` checkout. The manifest's source hashes support reproducibility and attribution, not a claim that every method of the larger graph has been ported or tested.

## Native workflows and resource review

The nine independent reference tests also exercise owning a chemically distinct RNA registry record after its registry is dropped, translating it to a copied graph, invalidating old IDs on clear, retaining duplicate-position metadata, and rolling back a merge or RNA digestion after a late conflicting/invalid parent. These are native invariants and source-derived workflows, not additional upstream literal goldens.

The separate resource audit checked peptide-parent parsing estimates against the actual named/numeric lookup and formula-copy paths, then checked RNA digestion's cumulative residue, product, work and logical-payload counters. RNA flanks use the source first raw-code byte and inclusive endpoints. A non-ASCII leading byte cannot be represented as a standalone Rust string and is rejected atomically.

One actionable issue was found and corrected: shared RNA parsing originally deducted the parsed payload only after constructing its residue vector. A nearly exhausted byte allowance could therefore allocate before rejecting the result. The shared parser now charges its container, context, terminal/residue payloads and conservative vector slots before growth, and charges the validation traversal. The ordinary public parser's successful scientific behavior is unchanged. Private regressions cover zero-byte failure before the first lookup and shared remaining counters. Read-only inspection confirmed the correction; no further concrete source, flank, merge/coverage or rollback discrepancy was found in this bounded review.

The focused nine-test suite passed on current Rust with all features and Rust 1.85 with no default features. Current strict Clippy and reference-file formatting also passed. The validation report records final whole-crate and post-fix compiler/feature results; these focused checks do not imply completion of the remaining identification graph layers.
